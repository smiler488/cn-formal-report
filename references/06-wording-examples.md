# 用户定稿用词对照（2026-11-25）

来源：用户手工修订《深圳AI研发与测试中心建设建议》政策依据调研报告 Word 成品。左列为生成稿原文，右列为用户定稿。生成同类政策依据调研、政府部门对接材料时逐条比对，右列为默认写法。

## 一、删除策论层与元话语

报告只写政策事实与条款，不写「我们打算怎么申报、怎么包装、怎么对接」。此类句子整句删除，不改写、不保留缩写版。

| 生成稿 | 用户定稿 |
|---|---|
| 项目申报主口径为面向真实世界的人工智能能力研发与测试公共服务平台 | 项目申报主要面向真实世界的人工智能能力研发与测试公共服务平台 |
| 申报主口径为面向真实世界的人工智能能力研发、测试与评测公共平台，不以农业人工智能中心作为对两部门的第一表述 | 整段删除 |
| 平台的产出为可复用的评测任务、基准、数据集与模型能力评估方法，直接对应…… | 整段删除 |
| 本次对接以人工智能平台立项取得两部门共识与书面意见，用地与农业资金另案衔接，并援引…… | 用地与农业资金可援引…… |
| 五、申报口径与政策窗口／（一）申报口径／（二）政策窗口／（三）名称与版本 | 五、申报政策，章内不设子标题，连续 5 段 |
| 申报口径按第五章调整 | 申报按第五章调整 |
| 资金口径方面 | 资金方面 |
| 部门归口方面，深圳市级人工智能重点方向未列农业…… | 深圳市级人工智能重点方向未列农业…… |
| 与建议稿逐条相关的条款见表1。 | 整句删除，表题直接出表 |
| 中国农业大学深圳研究院……该院具备项目承接主体的机构属性。 | 整段删除 |

## 二、去掉自评、拔高与术语化修饰

| 生成稿 | 用户定稿 |
|---|---|
| 最高位阶依据 | 最有力的依据 |
| 国家级赋权文件（两处） | 国家级文件 |
| 也是研发与测试中心概念可上溯的国家级源头 | 整句删除 |
| 研发与测试中心最直接的法规依据 | 研发与测试中心的法规依据 |
| 种植业为首选的高价值验证场景，不作为项目属性 | 种植业可作为高价值验证场景 |
| 与建议稿研发与测试中心的功能定位高度接近 | 与研发与测试中心的功能定位高度接近 |
| 两项内容与建议稿模型理解、归纳与推理研究及模拟推演与学习环境建设逐条对应 | 与模型理解、归纳与推理研究及模拟推演与学习环境建设逐条对应 |

保留的判断：「高度接近」「逐条对应」「对本项目支撑最直接的条款有六处」「具备纳入政策文本的条件」用户未改。用户禁用的是**自我拔高与包装话术**，不是一切程度词或关联判断。

## 五、标题去抽象关系词

| 生成稿 | 用户定稿 |
|---|---|
| 三、建设诉求与政策条款对应关系 | 三、建设诉求与政策条款 |
| 表3　建议稿核心诉求与政策条款对照 | 表3 核心诉求与政策条款 |
| 五、申报口径与政策窗口 | 五、申报政策 |

标题只留实体名词，删「对应关系」「对照」「口径」「窗口」「建议稿」。

## 六、组织方式与标点

- 「可争取事项有三项。一是……二是……三是……」挤在一段 → 「可争取事项有以下三项：」用冒号引出，三项各自独立成段。
- 文号、引用序号、著录目录统一用半角方括号 `[2025]`、`[9]`、`[1]`；全篇不用六角括号 `〔〕`，不混用。
- 表题用半角空格：`表1 《……》`，不用全角空格。
- 著录目录序号后不留空格：`[1]中共中央……`。
- 并列引号之间补顿号：`"……试验场'""支持……"` → `"……试验场'"、"支持……"`；`"国家人工智能应用中试基地""国家级检测认证机构"` → 中间加「、」。
- 相邻段落合并时删重复主语，如把「种植业能够提供……」与「种植业作为唯一能同时提供……」合为一段。

## 七、允许在段末加一句立意判断

用户主动补写：「深圳不占用耕地亦可主导标准与数据，加速人工智能认识、预测和改造世界。」

位置限于段落收束处，全篇至多一两处，不做通篇铺陈，不写成口号式小标题。

## 八、完整改写示例

**导语第三段**

生成稿：深圳市现行人工智能政策列举的重点方向未单列农业。深工信〔2025〕43号将「AI+」划为……五大领域〔9〕，……举例为药物研发、材料发现〔8〕。项目申报主口径为面向真实世界的人工智能能力研发与测试公共服务平台，种植业为首选的高价值验证场景，不作为项目属性。

用户定稿：……项目申报主要面向真实世界的人工智能能力研发与测试公共服务平台，种植业可作为高价值验证场景。

**国家依据段**

生成稿：该意见是深圳争取国家级创新载体落户的最高位阶依据，可用于论证中心属于国家支持深圳建设的重大创新载体范畴。

用户定稿：该意见是深圳争取国家级创新载体落户的最有力的依据，可用于论证中心属于国家支持深圳建设的重大创新载体范畴。

**第五章首段**

生成稿：申报主口径为面向真实世界的人工智能能力研发、测试与评测公共平台，不以农业人工智能中心作为对两部门的第一表述。深圳市人工智能政策的主责清单围绕……恰为上述政策共同需要的验证条件。

用户定稿：深圳市人工智能政策的主责清单围绕……恰为上述政策共同需要的验证条件。种植业作为唯一能同时提供……深圳不占用耕地亦可主导标准与数据，加速人工智能认识、预测和改造世界。

## 九、整词禁用「归口」「口径」（用户 2026-11-25 追加）

用户说明手工修订时「遗漏了剩下的归口和口径」，要求以后全篇不用。此前把这两词判为「客观职责陈述可保留」是错误结论，已废止。以下三处为定稿最终写法，生成时照此替换。

| 生成稿／残留写法 | 定稿最终写法 |
|---|---|
| 农业科研试验用地与农业专项资金归口深圳市乡村振兴和协作交流局 | 农业科研试验用地与农业专项资金由深圳市乡村振兴和协作交流局负责 |
| 作物生长、土壤与气象问题可归入生物与地球科学口径 | 作物生长、土壤与气象问题可归入生物与地球科学领域 |
| 表3 表头「归口部门」 | 表3 表头「责任部门」 |

替换词表：职责归属用「由……负责」「可与……联系」「属……职责」；分类用「领域」「方向」「方面」；表头用「责任部门」「可协同部门」「涉及部门」；标题只用实体名词。任何位置出现「归口」「口径」都算回退，含表题、表头、著录目录。

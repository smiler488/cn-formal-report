# 公文结构、标题与用词规范

## 层次与推进顺序

- 层次序号：`一、` → `（一）` → `1.` → `（1）`。不用论文式 `1 / 1.1 / 1.1.1`。
- 开篇用 2—4 段不编号导语总述事实与判断，不设「结论」「摘要」「核心判断」「总体判断」章。
- 正文按「依据—对应关系—职责—口径—条件—目录」推进；结论性判断融入导语或末章建议。
- 改结构时同步更新正文交叉引用，写作「第一章所列」「按第五章调整」等，不留下指向旧章节的引用。
- 同层级标题结构一致、字数接近。

## 标题写法

- 一律用名词性短语或动宾短语，一题只讲一件事。示例：战略定位、工业和信息化部门政策、协同部门、政策窗口、名称与版本、实施条件。
- 禁逗号、句号、顿号拆两事；禁完整判断句。
- 禁情态、时态、判断词：「已／须／应／需／将／为／有／具备／形成」。
- 禁「结论／摘要／核心判断」等论文式章节名。
- 反面例证（用户 2026-11-24 点名批评）：
  - 「（一）两级政策依据已成体系，申报口径须作调整」——判断句、逗号分拆两事、含「已」「须」。
  - 「（二）两部门职责有地方性法规依据，机构名称已变更」——判断句、逗号分拆两事、含「有」「已」。
- 主标题除上述规则外，还须满足单行要求（见 `01-format-rules.md`）。

## 用词红线

- 禁套话：「值得注意的是」「总的来说」「综上所述」「首先／其次／最后」式串联。
- 禁空泛动词与 buzzword：「赋能」「抓手」「闭环」「颠覆」「审计」（申报书场景另见 `04-user-profile.md`）。
- 禁破折号串联概念；破折号只作「——」使用。
- 术语首次出现给中文全称加英文缩写，如「人工智能（Artificial Intelligence，AI）」，其后用缩写。
- 数字用法按 GB/T 15835；文号用六角括号〔〕，年份不缩写。
- 不夸大方法价值；区分已发表成果、在研课题、研究构想、个人兴趣。
- 引用必须真实可查；不确定、无法核实的内容直接不写入正文，不写「需人工核实」。
- 引用来源分级：官方一手 > 权威媒体 > 企业白皮书；禁自媒体（知乎、小红书等）作为依据。
- 来源目录只列文件名称、文号、发文机关、日期、官方链接，不评级、不加核验说明。

## 标点与排版文字

- 中文全角标点；中英文数字之间不加空格。
- 图注在下、表题在上；正文先引用后出图表。
- 正式报告用「结论 → 关键理由 → 可执行计划 → 可选优化」组织思路，但成品中不写这四个标签。
- 表格中的解释性列（如「对建议稿的意义」「支撑强度评分」）属于辅助说明，不写入正文。

# 公文结构、标题与用词规范

## 层次与推进顺序

- 层次序号：`一、` → `（一）` → `1.` → `（1）`。不用论文式 `1 / 1.1 / 1.1.1`。
- 开篇用 2—4 段不编号导语总述事实与判断，不设「结论」「摘要」「核心判断」「总体判断」章。
- 正文按「依据—对应—职责—政策—条件—目录」推进；结论性判断融入导语或末章建议。章内可不设子标题，用户定稿第五章即为连续 5 段，不强行分节。
- 改结构时同步更新正文交叉引用，写作「第一章所列」「按第五章调整」等，不留下指向旧章节的引用。
- 同层级标题结构一致、字数接近。

## 标题写法

- 一律用名词性短语或动宾短语，一题只讲一件事。示例：战略定位、工业和信息化部门政策、协同部门、实施条件、建设诉求与政策条款、申报政策。
- 禁抽象关系词收尾：「对应关系」「对照」「口径」「窗口」「建议稿」一律不进标题与表题。用户定稿把「三、建设诉求与政策条款对应关系」改为「三、建设诉求与政策条款」、「表3　建议稿核心诉求与政策条款对照」改为「表3 核心诉求与政策条款」、「五、申报口径与政策窗口」改为「五、申报政策」。
- 禁逗号、句号、顿号拆两事；禁完整判断句。
- 禁情态、时态、判断词：「已／须／应／需／将／为／有／具备／形成」。
- 禁「结论／摘要／核心判断」等论文式章节名。
- 反面例证（用户 2026-11-24 点名批评）：
  - 「（一）两级政策依据已成体系，申报口径须作调整」——判断句、逗号分拆两事、含「已」「须」。
  - 「（二）两部门职责有地方性法规依据，机构名称已变更」——判断句、逗号分拆两事、含「有」「已」。
- 主标题除上述规则外，还须满足单行要求（见 `01-format-rules.md`）。

## 用词红线

- 禁套话：「值得注意的是」「总的来说」「综上所述」「首先／其次／最后」式串联。
- 禁空泛动词与 buzzword：「赋能」「抓手」「闭环」「颠覆」「审计」（申报书场景另见 `04-user-profile.md`）。
- 禁破折号串联概念；破折号只作「——」使用。
- 术语首次出现给中文全称加英文缩写，如「人工智能（Artificial Intelligence，AI）」，其后用缩写。
- 数字用法按 GB/T 15835；年份不缩写。文号与引用序号的括号形式以用户当前稿件为准：2026-11-25 用户定稿全篇统一用半角方括号 `[2025]`、`[9]`、`[1]`，不用六角括号 `〔〕`；同一文档内不得混用。
- 不夸大方法价值；区分已发表成果、在研课题、研究构想、个人兴趣。
- 引用必须真实可查；不确定、无法核实的内容直接不写入正文，不写「需人工核实」。
- 引用来源分级：官方一手 > 权威媒体 > 企业白皮书；禁自媒体（知乎、小红书等）作为依据。
- 来源目录只列文件名称、文号、发文机关、日期、官方链接，不评级、不加核验说明。

## 报告只写事实层（用户 2026-11-25 定稿提炼）

**核心原则：成品只列政策事实与条款，不写申报策略、话语包装、会商安排与自我论证。** 用户手工修订时删除的是一整层「策论叙述」，不是个别词汇。逐条改写对照见 `06-wording-examples.md`，生成时须比对该文件。

1. **禁策论元话语**：「主口径」「申报口径」「第一表述」「本次对接」「本次拜访」「另案衔接」「平台立项取得」「书面意见」「政策窗口」不写入正文与标题；涉及用地与资金时直接写可与哪个部门联系、援引哪一条款。
2. **禁自我论证段**：不写「平台的产出为……直接对应……」「与建议稿逐条相关的条款见表N」「该院具备项目承接主体的机构属性」等替读者做映射与资质论证的整段。表题直接出表，不加引导句。
3. **禁自评拔高**：不用「最高位阶」「国家级赋权文件」「可上溯的国家级源头」「最直接」「首选的」「不作为项目属性」。程度词可用平实说法「最有力的依据」。客观关联判断不在此列，「高度接近」「逐条对应」「对本项目支撑最直接的条款有六处」「具备纳入政策文本的条件」用户均保留。
4. **弱化断言**：多用「可作为」「可与……联系」「可援引」，少用「为」「由……归口」「应」「须」。删防御性界定句（「不作为项目属性」「不以……作为第一表述」）。
5. **机构用实名**：写「工信局和科创局」「市乡村振兴和协作交流局」，不用「本次拜访两部门」这类场景指代；表头用「可协同部门」，不用「归口部门」。「归口」作客观职责陈述（「农业专项资金归口某局」）允许保留。
6. **删段落分类标签**：「部门归口方面，」这类带策论味的段首标签删掉；「政策时效方面」「用地合规方面」「主体资质方面」「资金方面」等纯事项标签保留。
7. **并列事项分列**：「可争取事项有以下三项：」用冒号引出，三项各自独立成段，不用「一是……二是……三是……」挤在一段。
8. **允许段末立意句**：可在段落收束处补一句提升立意的判断（如「加速人工智能认识、预测和改造世界」），全篇至多一两处，不铺陈、不设口号式小标题。

## 标点与排版文字

- 中文全角标点；中英文数字之间不加空格。
- 图注在下、表题在上；正文先引用后出图表。
- 正式报告用「结论 → 关键理由 → 可执行计划 → 可选优化」组织思路，但成品中不写这四个标签。
- 表格中的解释性列（如「对建议稿的意义」「支撑强度评分」）属于辅助说明，不写入正文。
